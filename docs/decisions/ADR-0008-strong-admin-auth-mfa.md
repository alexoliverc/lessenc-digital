# ADR-0008 — Admin com autenticação forte e MFA

**Status:** ACCEPTED — baseline documental P02, 11/09/2026.

**Decisão:** acesso administrativo requer identidade individual, autenticação forte, MFA, sessões seguras, autorização server-side por operação, auditoria e rate limiting. Interface não edita arbitrariamente estados financeiros.

**Consequência:** tecnologia/provedor de autenticação **OPEN**; nenhuma autenticação foi implementada por esta decisão documental. [Segurança](../security/application-security-baseline.md).
